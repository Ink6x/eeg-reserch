## Executive Summary

### 主要結果
1. **Window 拡大は仮説通り強く効いた**: 750 サンプル (1500ms) が最良。 S1 (+0.067) と S9 (+0.078) で大幅改善。
2. **損失関数では bce_weighted が最良**: focal を平均 +0.026 上回る。 特に S9 で +0.061 の差。
3. **仮説 A1 (Focal の 0.5 局所安定) は反証**: focal の near_0.5 = 0、 むしろ bce_weighted のほうが集中。
4. **被験者間で最適パラメータが異なる**: S5 は window 拡大で改善しない（個人差）。

### 重要な発見

**S9 が DL で初めて LR を超えた** (LR=0.673):
- v2 EEGNet: 0.546 (-0.127)
- v4 ablation w=500 + bce_weighted: **0.7636** (+0.091)
- v4 ablation w=750 + focal: **0.7594** (+0.086)

**v2 RCA で「DL が最も苦戦していた被験者」が、 提案手法の有効性を最も強く示した。**

### 推奨設定 (v4 本番訓練)
- `WINDOW_SAMPLES = 750`
- `LOSS_TYPE = "bce_weighted"`
- ただし S5 type の被験者には window=375 もテスト価値あり

## 1. Window Ablation 結果

### 1.1 数値

| 被験者 | LR | w=250 | w=375 | w=500 | w=750 | 最良 (Δ vs LR) |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| S1 | 0.7739 | 0.7725 | 0.7883 | 0.7790 | **0.8397** | +0.066 |
| S5 | 0.6670 | **0.6859** | 0.6703 | 0.6706 | 0.6668 | +0.019 (w=250) |
| S9 | 0.6729 | 0.6818 | 0.6962 | 0.7426 | **0.7594** | +0.087 |
| **Mean** | 0.7046 | 0.7134 | 0.7183 | 0.7307 | **0.7553** | +0.051 |

### 1.2 学習曲線パターン

`n_epochs_run` から読み取れること:
- S1, w=250 と w=375 は early stop（28-36 ep）→ 早期に収束
- S1, w=750 は patience=12 まで使い切らず 50 ep 完走
- S5 は全条件で 48-50 ep → 学習が遅い、 表現力不足の兆候

### 1.3 仮説 S2 (RP 時間スケール) の検証

**仮説**: Bereitschaftspotential (RP) は -1500ms から発生するため、 window 500ms (250 sample) では情報が不足する。

**結果**: 12 通りの結果のうち、

| 被験者 | 仮説支持か | 効果サイズ |
|:---:|:---:|:---:|
| S1 | ✅ 強く支持 | +0.067 (250→750) |
| S5 | ❌ 反証 | -0.019 (250→750) |
| S9 | ✅ 強く支持 | +0.078 (250→750) |

→ **平均では支持 (+0.042)**、 ただし **S5 では逆効果** という大事な「個人差」が発見された。

### 1.4 S5 の異常性についての考察

**S5 は LR ベースラインも 0.667 と最低クラス。 Window 拡大で改善しない理由の仮説**:

1. **信号品質低**: 全フレームでアーチファクトが多く、 長い window はノイズを増やす
2. **早期 RP の不在**: 個体差で RP の早期成分が弱く、 -500ms 以前に有用情報がない
3. **過学習の早期発生**: 長い window で容量過剰 → 過学習
4. **イベント間隔が短い**: window=750 (1.5s) が前イベントの影響を含む

→ Phase 2.5 の被験者別深掘り分析で要検証。

### 1.5 訓練時間

| Window | 平均訓練時間/被験者 (秒) | 倍率 |
|:---:|:---:|:---:|
| 250 | 329 | 1.0x |
| 375 | 505 | 1.5x |
| 500 | 670 | 2.0x |
| 750 | 990 | 3.0x |

12 被験者 × Conformer (3-4× 重い) で、 window=750 だと **〜5-6 時間** で全員訓練可能。 Kaggle T4 budget 内。

## 2. Loss Comparison 結果

### 2.1 数値

| 被験者 | LR | focal | bce_weighted | bce_plain | 最良 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| S1 | 0.7739 | **0.8142** | 0.8031 | 0.7987 | focal (+0.040) |
| S5 | 0.6670 | 0.6946 | **0.7230** | 0.7030 | bce_weighted (+0.056) |
| S9 | 0.6729 | 0.7026 | **0.7636** | 0.6727 | bce_weighted (+0.091) |
| **Mean** | 0.7046 | 0.7371 | **0.7632** | 0.7248 | **bce_weighted** (+0.058) |

### 2.2 仮説 A1 検証 — 反証された

**仮説 A1**: Focal loss は 0.5 周辺の予測が局所安定になり、 学習が抜け出せなくなる。

**実装**: 最終 epoch の予測確率分布を bin 化し、 0.4-0.6 範囲の比率 (`near_half_ratio`) を計測。

**結果**:

| 損失 | S1 | S5 | S9 | Mean |
|:---:|:---:|:---:|:---:|:---:|
| focal | 0.0000 | 0.0000 | 0.0000 | **0.0000** |
| bce_weighted | 0.3326 | 0.1664 | 0.0001 | 0.1664 |
| bce_plain | 0.0000 | 0.0000 | 0.0000 | 0.0000 |

**結論**: ❌ **仮説 A1 は反証**
- Focal loss の near_0.5 比率は完全に 0 → 0.5 周辺に集中していない
- むしろ bce_weighted で集中（S1 で 33%）
- これは bce_weighted の高い `pos_weight` (~37) が classifier を不確実な状態に押し上げている可能性

### 2.3 なぜ bce_weighted が勝つのか

**仮説 (再生成)**:

bce_weighted は positive クラスの BCE 損失を `pos_weight × log(1 - p)` の形で増幅する。

```python
# pos_weight ≈ 37 (各イベントの neg/pos 比)
pos_count = ~16K, neg_count = ~600K → pos_weight ≈ 37
```

これにより:
- 正例の損失寄与が 37 倍
- model は正例を見逃すと大きなペナルティ
- → 結果として正例の確率が増加 (0.5 周辺に集中する分布)
- → AUC が向上 (positive を high score にしやすい)

**Focal loss との違い**:
- Focal: `(1-p)^γ` で easy example を抑制 → hard example だけ訓練される
- BCE+weights: 全 sample で正例に重み付け → より一様に学習

**EEG での示唆**: クラス不均衡 (2.6%) に対して、 focal は **過剰** な正則化だった可能性。 bce_weighted のほうが情報量を保っている。

### 2.4 S1 で focal が勝つ理由

S1 は LR baseline が高く (0.774)、 信号品質が良いと推定される。 信号品質が高いとき:
- BCE は容易な negative の損失を蓄積するため model が drift しやすい
- Focal は easy negative を抑制し、 hard example に集中 → わずかに有利

S5, S9 のような低品質信号では bce_weighted が勝つ。 → **被験者ごとの最適 loss が異なる** という洞察。

## 5. 思考過程の記録

### 5.1 結果を見る前の予想と実際

**予想 (Phase 2.0 計画時)**:
- Window 拡大: +0.02-0.05 → **実際 +0.04 平均、 S1/S9 で +0.07-0.08** (予想以上)
- Focal vs BCE: focal が勝つと予想 → **bce_weighted が勝った** (反予想)
- 仮説 A1 (focal 0.5 集中): true → **false** (反証)

### 5.2 反証された仮説の取り扱い

仮説 A1 は私が **理論的に正しいと信じて立てた** ものだったが、 実験で反証された。 これは:
1. **正直に記録する**: ポートフォリオで隠さない
2. **代替仮説を立てる**: bce_weighted が勝つ別の理由 (pos_weight × 不均衡)
3. **過剰一般化を避ける**: 3 被験者の結果なので、 12 被験者で再確認必要

### 5.3 個人差の発見

**S5 の異常性** は当初予想していなかった発見。 「全被験者で window 拡大が効く」と素朴に考えていたが、 実際は被験者依存。
- これは **subject embedding** や **per-subject ハイパーパラメータ最適化** の重要性を示唆
- Phase 3 (v5: cross-subject + subject embedding) で理論的に対応可能

### 5.4 次に学ぶべきこと

1. **per-subject 最適化はどこまで価値がある?** (個別調整の労力 vs 自動化)
2. **bce_weighted の pos_weight は ablation 必要?** (現在 37 自動計算、 best ではないかも)
3. **window=750 + augmentation の組合せ効果**
