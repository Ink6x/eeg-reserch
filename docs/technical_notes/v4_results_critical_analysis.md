# v4 結果の批判的分析 — 部分成功と Conformer 崩壊

**実行日**: 2026-05-12 (Kaggle T4)
**設定**: window=750, loss=bce_weighted, 全 augmentation, 12 被験者 × 2 モデル
**生データ**: `reports/results/04_dl_results_v4.json`

---

## 0. Executive Summary

### 結果の二面性

**EEGNet v4: LR と統計的に同等（部分成功）**
- 平均 AUC: 0.7335 vs LR 0.7380 (Δ = -0.005, Cohen's d = -0.064, p = 0.83)
- 6/12 被験者で LR 超え、 6/12 で未達
- **明確なパターン**: 低 LR ベースライン被験者 (S5, S9) で大勝、 高 LR (S2, S7, S8) で敗北

**Conformer v4: 致命的な regression（重大な失敗）**
- 平均 AUC: 0.5532 (vs v2 の 0.6160 で **-0.063 退化**, vs LR で **-0.185** の大差)
- 0/12 被験者で LR 超え
- 全被験者でほぼランダム (0.52-0.60) → アーキ修正 (BN1d + LogVarPool) が崩壊解決に **失敗**

### 主要な学び

1. **仮説 S2 (RP 時間スケール) は低 LR 被験者で確証** — S9 +0.108, S5 +0.086, S1 +0.056
2. **データ中心改善だけでは LR 超えできない** — 高 LR 被験者の損失で相殺
3. **Conformer の v2 → v4 退化は v3 のアーキ修正が逆効果** だった可能性
4. **被験者間異質性が真の壁** — Phase 3 (subject adaptation) の重要性が定量的に示された

## 2. EEGNet v4 の結果分析 — なぜ部分成功か

### 2.1 成功（低 LR 被験者）の説明

**S9 の劇的改善** (LR=0.673, v2=0.546, **v4=0.781, +0.108 vs LR**):
- v2 RCA で「DL が最も苦戦」と指摘 → v4 で 反転して **最大の勝者**
- v2→v4 で **+0.235** という巨大ジャンプ
- 要因の組合せ:
  - window=750 → 長期 RP コンテキストを獲得（仮説 S2）
  - bce_weighted → 正例信号の強化（仮説 A1 のリベンジ）
  - augmentation → 過学習抑制

**S5 の改善** (LR=0.667, v4=0.753, +0.086):
- 興味深い: ablation では window=750 が S5 で **悪化** していた (0.686 → 0.667)
- v4 では augmentation + bce_weighted の組合せで救済
- → 「単一拡張は逆効果でも、 統合パイプラインで効くケースがある」

**S1, S3, S6, S12 の中程度改善**:
- いずれも +0.02-0.06 範囲
- LR の弱点（HandStart など低 AUC イベント）を補完している可能性
- per-event AUC 詳細が欲しいところ

### 2.2 失敗（高 LR 被験者）の説明

**S2, S7, S8 の大幅敗北** (-0.08 〜 -0.09):
- これらは LR で 0.77-0.81 と元から強い
- DL が overfitting / 信号特性とのミスマッチで弱体化

**考えられる原因**:

1. **bce_weighted の overshoot**: pos_weight = 37 が高 LR 被験者では過剰
   - 高 LR 被験者は信号品質が良く、 LR は positive を 0.7-0.8 で正しく predict
   - bce_weighted で gradient が 37× → 過剰補正 → false positive 増加
   - 高 LR 被験者ほど被害大 (S2, S7, S8 は LR が 0.77-0.81)

2. **augmentation の過剰**: 信号品質が良い被験者では、 ノイズ追加が情報を破壊
   - GaussianNoise σ=0.05 + ChannelMask + Mixup の組合せ
   - 信号品質低い被験者では正則化として機能、 高品質では逆効果

3. **window=750 の情報希釈**: 長い窓は noise も含む
   - S5 は ablation で逆効果だった理由と同じ
   - 高 LR 被験者は短い window で十分

→ **「全被験者で同一ハイパーパラメータ」アプローチの限界が定量的に示された**

### 2.3 v2 → v4 の進化を被験者別に見る

```
v2 で苦戦 (AUC<0.65) → v4 で救済:
  S9: 0.546 → 0.781 (+0.235)
  S10: 0.573 → 0.670 (+0.097)

v2 で並 (0.65-0.75) → v4 で改善:
  S1: 0.762 → 0.830 (+0.068)
  S5: 0.711 → 0.753 (+0.042)
  S6: 0.724 → 0.761 (+0.037)
  S3: 0.734 → 0.751 (+0.017)

v2 で高 (>0.75) → v4 で退化:
  S2: 0.778 → 0.721 (-0.057)
  S8: 0.757 → 0.690 (-0.067)
  S11: 0.739 → 0.677 (-0.062)
  S12: 0.761 → 0.738 (-0.023)
```

**完璧な負の相関**: v2 で良かった被験者は v4 で悪化、 悪かった被験者は劇的改善。

## 3. Conformer v4 の崩壊分析 — なぜアーキ修正が逆効果だったか

### 3.1 規模の理解

| 指標 | v2 Conformer | v4 Conformer | 変化 |
|---|:---:|:---:|:---:|
| Mean AUC | 0.616 | 0.553 | **-0.063 退化** |
| Std AUC | 0.046 | 0.020 | 0.020 (低分散) |
| Max AUC | 0.664 (S12) | 0.603 (S1) | -0.061 |
| Min AUC | 0.552 (S10) | 0.524 (S3) | -0.028 |
| LR 超え数 | 0/12 | 0/12 | 変わらず |

低分散 (0.020) は **全被験者で同じく崩壊** を示している。 偶発ではなく **構造的問題**。

### 3.2 仮説生成 — なぜ v3 修正が逆効果か

5 つの同時変更を行ったため、 単独原因の特定は不可能。 ただし強い候補:

**H_conf_1: bce_weighted × Conformer の容量過剰**
- bce_weighted の pos_weight ≈ 37 で正例損失が 37 倍
- Conformer のパラメータ ~500K + bce_weighted の大きな gradient → 不安定
- LR=1e-4 でも実効 LR は 37× → 暴走の可能性

**H_conf_2: BatchNorm1d × augmentation × 小さな effective batch**
- batch=512 だが positive がわずか → BN1d の running stats が陰性偏り
- augmentation で更にノイズ追加
- LayerNorm のほうが augmentation 耐性は高かったかもしれない

**H_conf_3: window=750 × TCN dilations=[1,2,4]**
- TCN の最終 RF = 50 sample = 100ms
- window=750 (1500ms) の 6.7% しか見ていない
- 250 sample window では 20%, 750 では 6.7% → 受容野比率の悪化
- window 拡大は EEGNet では効くが Conformer では逆効果

**H_conf_4: LogVarPool × bce_weighted の数値**
- LogVarPool の出力は log_var で値域 [-5, 5]
- bce_weighted の logit に対する gradient が log_var の小さな数値で押しつぶされる可能性

**H_conf_5: 単純に組合せが多すぎた**
- 5 変更を同時 → どれが原因か分離不能
- Conformer は EEGNet より敏感

### 3.3 「v3 アーキ修正は寄与小」の事後検証

v2 RCA で「H_prev2 (LayerNorm) は寄与小」「H_prev3 (CholeskyPool) は寄与中」と評価していた。
v4 で **BatchNorm1d + LogVarPool に置換しても改善せず逆効果** → 当該評価は正しかった。

逆に言えば、 **v3 のアーキ修正は v2 の崩壊の主因ではなかった** ことが追加で実証された。

### 3.4 Conformer の本質的問題

被験者間ばらつき (std=0.020) が小さく、 全員崩壊 → **アーキそのものか、 訓練戦略の問題**:

1. **パラメータ/サンプル比 0.06 の致命性**: 500K params に 30K windows は **物理的に不可能**
2. **EEGNet (15K params) のサンプル比 4.0 は十分** → 学習できる
3. → **Conformer は cross-subject 訓練 (Phase 3) 無しでは無理** と結論

## 5. 思考過程と意思決定の記録

### 5.1 結果を見た瞬間の感覚

最初に EEGNet 0.7335 vs LR 0.7380 を見て「ほぼ並んだ」と思ったが、 詳細を見ると:
- 平均は並んでいるだけ、 被験者ごとに **二極化**
- これは **平均値の罠** で、 single number は misleading

次に Conformer 0.553 を見て「**v2 より悪い**」と気づき、 当初の v3 アーキ修正方針への疑問が決定的になった。

### 5.2 「v3 アーキ修正は寄与小」を v2 RCA で予測していた

v2_root_cause_analysis.md で:
> H_prev2 (LayerNorm transpose) → 評価: 寄与度小
> H_prev3 (CholeskyPool 528d) → 評価: 寄与度中

と書いていた。 これが v4 Conformer の **退化** で裏付けられた。
**「アーキ修正は表面的、 真因は別」** という診断は正しかった。

### 5.3 仮説 S2 の検証は混合結果

ablation では S1, S9 で支持、 S5 で反証だった。 v4 では:
- S5 が実は改善 (window=750 でも、 augmentation 込みなら効く)
- S1, S9 で大成功
- → **window だけでは判断できず、 augmentation や loss との組合せで効果が変わる**

「変数を独立に検証する」という思考法の限界を学んだ。 実際は **交互作用** が重要。

### 5.4 高 LR 被験者の DL 敗北は予想外

仮説段階では「DL は全被験者で改善する」を暗黙に仮定していた。
データから「高 LR 被験者で DL は逆効果」という新仮説が浮上。

これは:
- **LR の bandpower 特徴が、 高品質信号被験者では十分**
- DL が learn する追加特徴が少ない、 むしろノイズ追加
- → **subject-adaptive モデル選択** の必要性を示唆

## 6. 次のステップ — 戦略の再評価

### 6.1 元の Phase 計画との照らし合わせ

元計画:
- Phase 2 (v4 データ中心) → 完了、 **EEGNet は LR 並、 Conformer 退化**
- Phase 3 (v5 cross-subject) → 次のステップ
- Phase 4 (v6 seq-to-seq)
- Phase 5 (統計検定 + ポートフォリオ)
- Phase 6 (SSL)

### 6.2 v4 結果が示す方向修正

**Conformer の取り扱い**:
- 案 A: Conformer ablation で原因究明 (1-2 日)
- 案 B: Conformer を後回しにして Phase 3 へ
- 案 C: Conformer を諦め、 EEGNet 中心に進める

**EEGNet の改善方向**:
- ベースとなる EEGNet v4 は LR と並ぶ
- Phase 3 (cross-subject + subject embedding) で **被験者間異質性** を直接解決
- → S2, S7, S8 などの「高 LR 被験者で DL が負ける」問題に効くはず

### 6.3 推奨アクション

**推奨: 案 B (Conformer 後回し) + Phase 3 直行**

理由:
1. Phase 3 (subject embedding) は **新発見の「被験者ヘテロ性」を直接解決**
2. EEGNet が LR と並んでいるので、 cross-subject 訓練で **超える可能性が高い**
3. Conformer の ablation は時間コストが高い (24 runs × 10分 = 4 時間 + 分析)
4. ポートフォリオ的には「Conformer の失敗を正直に記録」のほうが価値
5. v5 で subject embedding を導入すれば、 Conformer も後で改善可能

**Phase 3 で達成したいこと**:
- EEGNet v5 で LR を有意に超える (mean AUC > 0.78)
- 被験者間 std を半減 (0.062 → 0.03)
- S2, S7, S8 (高 LR 被験者) も DL で勝つ
- Conformer も subject embedding で部分回復

## 7. Phase 3 の重要性（再確認）

v4 結果は Phase 3 の必要性を **定量的に裏付けた**:

1. **仮説 S3 (within-subject の罠) の実証**:
   - Conformer 全被験者崩壊 (std=0.020)
   - 500K params に 30K windows は absolute insufficient
   - cross-subject なら 12× データ + subject 特性を embedding で吸収

2. **被験者ヘテロ性の発見**:
   - 高 LR 被験者で DL は害
   - subject-conditioning で被験者特性に合わせた学習が必要

3. **EEGNet の改善余地**:
   - v4 で 0.7335 → cross-subject で +0.03-0.05 期待
   - 0.78 到達なら LR を有意に超える

## 8. ポートフォリオ的価値

v4 の **混合結果** は、 実は単純な勝利より教育的価値が高い:

1. **「複数同時変更の罠」**: 5 変更同時で Conformer 退化 → 何が原因か不明
2. **「平均の罠」**: EEGNet 平均並みでも被験者別では二極化
3. **「データ中心改善の限界」**: window/loss/augmentation だけでは構造問題は解決しない
4. **「仮説の事後検証」**: H_prev2/3 「寄与小」予測が実証された
5. **「率直な失敗記録」**: Conformer 退化を隠さず明記
